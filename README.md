# JavaScript Task Manager

A simple, responsive task manager built with HTML, CSS, and vanilla JavaScript. Tasks are saved in the browser using localStorage, so they remain available after refreshing or reopening the page.

## Features

- Add new tasks.
- Mark tasks as completed.
- Visual strikethrough for completed tasks.
- Delete tasks.
- Automatically save tasks using localStorage.
- Restore saved tasks when reopening the page.
- Display an empty state when there are no tasks.
- Responsive layout for mobile and desktop.

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
- Browser localStorage

## Running Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/ddelportgit/javascript-task-manager.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser.

No additional dependencies or installation required.
